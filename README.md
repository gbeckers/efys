efys
====

Efys is a python library to help analyzing neural electrophysiology data.

Requirements
------------
Efys depends on the following Python libraries:

* darr
* matplotlib
* mne
* numpy
* pandas
* pyedflib
* soundfile
* uts

Install
-------
Since we are in early development, install from github:

    $ pip install git+https://github.com/gbeckers/efys@master
